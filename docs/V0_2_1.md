# RiftChatModern v0.2.1 — full message reader and addon console mirroring

November 20, 2026 — AMD-DESKTOP. Standalone original Lua 5.1 addon. This release improves practical chat readability and makes existing diagnostic console output from other RIFT addons accessible through the replacement.

## Full message reading

Click any visible message row to open a dark overlay containing the **complete saved text**, without the shortened 79-character list preview. COPY MESSAGE sends that one source/message to the Windows clipboard using RIFT's clipboard API. CLOSE returns to the list. COPY HISTORY still copies all filtered messages.

Stable message IDs keep selections associated with the same record across paging and filters. Cleared or evicted messages become unavailable rather than silently pointing to another row.

The input command **:copy** now invokes actual clipboard copying rather than printing a placeholder.

## Inspect RIFT native console subscriptions

The **:native** command and GetNativeConsoles() API now use Inspect.Console.List() and Inspect.Console.Detail() when available. Results include up to 32 native console identifiers, names and Boolean subscriptions such as say, tell, party, guild, NPC, system, and combat.

This is **channel configuration metadata, not the native chat transcript**. No native UI frames are modified or given synthetic focus.

Installed primary API references: RIFT_API_Docs/LLM_RIFT_API/Console/inspect_console_list.md and inspect_console_detail.md.

## Optional addon output mirroring

The button labeled MIRROR OFF toggles capturing calls made by other addons through Command.Console.Display. Editor commands are **:mirror on**, **:mirror off**, and **:mirror status**.

The global addon API provides SetConsoleMirror(boolean) and GetConsoleMirrorStatus().

When explicitly enabled, a bounded pass-through wrapper forwards to RIFT's original Command.Console.Display exactly once and preserves its returns and errors. A copy of the message appears in RiftChatModern's Addons history; limited HTML markup is converted to plain text. Recursion is prevented, and the new addon does not capture its own versioned startup notices.

If another addon installs a wrapper after ours, disabling the mirror will **not overwrite that newer wrapper**. Capture is disabled, and restoration conflict is returned. The default mirror state is **OFF**.

Only **addon-generated console output after enabling** is captured. This does not retrieve existing native chat history or ordinary player say/tell/guild/party messages.

## Event callback compatibility

NPC and notification handlers support both (info) and (event, info) callback shapes. A bounded unit-indexed set of text notifications can also be recorded; nontext values are ignored. Live client validation remains necessary to establish actual event shapes.

## Validation

Run in PowerShell from C:\work\RiftChatModern:

    & "C:\work\riftreader2\.venv\Scripts\python.exe" -B -m unittest discover -s tests -v

Tests exercise the real Lua 5.1 interpreter with fake game APIs: message selection and copying, stable history IDs, console wrapper passthrough/restore/conflicts, callback shapes, channel configuration metadata, RPT adapter, addon-to-addon messaging, drag, focus, SavedVariables, clipboard, and bounded history.

**Physical RIFT verification is still pending:** the installed release needs an in-game UI reload, window/drag/focus/clipboard acceptance and a bounded opt-in mirror test. No Lua mock test is represented as real game acceptance.

## Shared value

RR2, RRECollector, RPT and other addons can now publish into RiftChatModern explicitly through its API or, when enabled, have their existing Command.Console.Display diagnostics mirrored without modifying their repositories. For ordinary player social chat, reuse the mature LuaPadModern external Log.txt watcher as a separate candidate before developing a new host reader.

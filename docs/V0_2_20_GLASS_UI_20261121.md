# RiftChatModern v0.2.20 — Glass UI visual refresh

**Date:** November 21, 2026

**Repo:** `C:\work\RiftChatModern` · **Runtime:** RIFT Live / Lua 5.1

## Goal

Bring the real in-game RCM diagnostics/chat-style window toward the
approved reference: translucent charcoal surfaces, subtle cyan glowing
outlines, rounded tabs, readable colored messages, and modern controls.
This is a functional Lua UI redesign, **not a static replacement screenshot**.

## Implementation

- 12 original, transparent PNG textures generated deterministically by
  [`tools/create_ui_textures.py`](../tools/create_ui_textures.py).
- Real `UI.CreateFrame("Texture")` instances load packaged textures with
  `Texture:SetTexture("RiftChatModern","textures/<asset>.png")`.
- Existing interactive frames remain the controls; texture children are
  non-interactive, placed on low render layers. No keyboard or mouse binding
  was reassigned.
- Rounded glass backgrounds for main window, title bar, history, detail
  reader, and input fields; idle/active/hover tabs and action buttons.
- Active tab visual states track the real filter; mouse hover restores its
  prior state. The RUN button gets a bright accent.
- A narrow color bar marks populated message rows while preserving clickable
  details, original message text, and explicit HOST/import provenance.
- Skins resize with the actual window and do not introduce new SavedVariables.
- Failed/unsupported texture loading falls back to the existing dark colors.
- Lua 5.1's 60-upvalue function limit was caught by compilation and fixed
  at the root: new plate state lives in the existing `controls._skin` table
  rather than adding multiple function captures.
- `deploy_rcm.py` supports new packaged subfolders after verifying no
  existing symlink or file occupies the path. Created directories are removed
  during rollback when empty. No other addon or character saves are touched.

## Safety of historical data and behavior

The message model and storage schema remain version 2; existing history,
character preferences, addon-data messaging, host import commands,
filter/search, editor focus, resizing, clipboard controls and RPT Lab
integration are retained.

**Important:** The approved visual reference showed native Guild/Party/Say
examples for illustration. RCM v0.2.20 does **not** claim to capture or
transmit ordinary native player chat. Host imports remain `HOST/...`
and native RIFT chat remains available.

## Physical acceptance checklist

1. Ensure RIFT is visible and the user controls its foreground.
2. In original game chat, enter `/reloadui` exactly once to load v0.2.20.
3. Verify initialization displays `RiftChatModern v0.2.20`.
4. Open with `/rcm`; check translucent corners, cyan outlines, and tabs.
5. Check hover, tab clicks, search, editor focus, RUN, drag and resize.
6. Inspect import provenance and long-message detail overlay.
7. Check for in-game Addon Error alerts and capture a **real screenshot**.
8. Compare against the approved reference; refine only after observed
   physical discrepancies, preserving function and data contracts.

Offline mocks cannot establish physical rendering quality or game runtime
activation. An installed file hash is not proof that `/reloadui` was run.
